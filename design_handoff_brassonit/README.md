# Handoff: 브라소닛(brassonit) — 연예인 섭외대행 · 공연기획 사이트

## Overview
연예인 섭외대행/공연기획사 "브라소닛"의 웹사이트 디자인입니다. 아티스트 탐색(카테고리/검색) → 찜/장바구니 → 견적서 작성 → 견적내역 확인의 섭외 견적 흐름과, 기획공연 목록/상세, 회원가입·로그인(이메일 인증 시뮬레이션)을 포함합니다.

## About the Design Files
이 번들의 파일은 **HTML로 제작된 디자인 레퍼런스(프로토타입)**입니다. 의도된 화면과 동작을 보여주기 위한 것이며, 프로덕션 코드로 그대로 복사하는 용도가 아닙니다. 과제는 이 디자인을 **대상 코드베이스의 기존 환경(React, Vue, Next.js 등)과 그 관례·라이브러리로 재구현**하는 것입니다. 환경이 아직 없다면 프로젝트에 가장 적합한 프레임워크를 선택해 구현하세요.

`Brassonit.dc.html`은 커스텀 컴포넌트 포맷입니다. 구조는 다음과 같이 읽으면 됩니다:
- `<helmet>` 안의 `<style>` = 전체 CSS (클래스 정의)
- `<x-dc>` 본문 = 화면 마크업. `{{ name }}`은 데이터 바인딩, `<sc-if value>`는 조건부 렌더링, `<sc-for list as>`는 리스트 반복
- 하단 `<script data-dc-script>`의 `Component` 클래스 = 상태와 이벤트 로직 (`state`, `renderVals()`가 템플릿에 값·핸들러 공급)

## Fidelity
**High-fidelity.** 색·타이포·간격·인터랙션 모두 최종 의도입니다. 픽셀 단위로 재현하되, 아티스트/공연 데이터와 이미지는 데모용(picsum.photos 플레이스홀더)이므로 실제 데이터/이미지로 교체합니다.

## 전역 레이아웃
- 컨테이너 `.wrap`: max-width 1440px, 좌우 패딩 96px (모바일 620px 이하 20px), 가운데 정렬
- 페이지 구조: 헤더 → GNB(sticky) → main(flex:1) → 푸터. **푸터는 짧은 페이지에서도 화면 하단에 고정** (body min-height:100vh, flex column, main flex:1)
- **라운딩 8px로 통일** — 이미지·썸네일·버튼·검색창·입력·칩·드롭다운 모두 border-radius 8px (원형 요소만 50%). 두꺼운 2px 검정 보더가 핵심 시각 언어

## Screens / Views

### 1. 헤더 (전 화면 공통)
- 로고 "brassonit" (26px/800, 액센트 색 `var(--color-accent)` 기본 #B57EDC) + 그 아래 `공연기획사 브라소닛` (13px/600, #888) — 클릭 시 홈
- 검색창: flex:1, max-width 640px, border 2px solid #000, height 48px, 돋보기 아이콘 + placeholder "어떤 아티스트를 찾으세요?", Enter 시 검색 결과 화면. **포커스 시에도 보더는 2px 검정 유지 — 액센트(보라) 보더/아웃라인을 추가하지 않음** (키보드 :focus-visible만 액센트 아웃라인)
- 우측(비로그인): 회원가입(텍스트 버튼) / 로그인(2px 검정 보더 버튼)
- 우측(로그인): **사용자 아이콘 + 하트(찜) 아이콘 + 장바구니 아이콘**(담긴 수를 액센트색 배지로 표시) — 이 순서
  - 사용자 아이콘 클릭 → 드롭다운(우측 정렬, 8px 라운딩, 그림자): `{이름}님`(**링크 없음, 플레인 텍스트**, 13px/600, 하단 1px #ddd 룰) / 회원정보(→ 회원정보 수정) / 견적내역 / 로그아웃(상단 구분선, #888). **찜리스트 항목 없음** — 헤더 하트 아이콘이 대신함

  - 장바구니 아이콘 클릭 → 장바구니 페이지 (비로그인 시 로그인 유도)

### 2. GNB (sticky, top 0)
- 카테고리 탭: 대중가수 · 음악 · 강연 · 사회자 · 퍼포먼스. 활성 탭은 하단 3px 액센트 밑줄
- 데스크톱 메가메뉴: **GNB 바 전체가 아니라 메뉴 탭 영역(대중가수~퍼포먼스 폭, 탭 수에 따라 자동 확장)에 hover했을 때만** 열리고, 열린 패널 위에 마우스가 있는 동안 유지. 패널은 화면 전체 폭, 그림자 없음, 하단 1px #e5e5e5 룰만. 내부 컬럼은 페이지 컨테이너에 정렬. **사용자 드롭다운에서 항목을 클릭해 이동한 직후에는 마우스가 GNB 위에 있어도 메가메뉴를 열지 않음** (마우스가 한 번 벗어나면 해제)
- 모바일(620px 이하): 탭 가로 스크롤, 메가메뉴 대신 목록 페이지 상단에 하위 장르 칩 바

### 3. 홈
- 히어로 (풀블리드 무대 배경): 사진 대신 **CSS로 그린 어두운 무대 씬**이 배경. 화면 양 끝까지(100vw) 확장, 상단은 GNB 바로 아래에서 시작해 하단은 "브라소닛 기획공연" 섹션 룰 직전까지(하단 마진 0), min-height 500px, 배경 #0d0d12
  - 조명 애니메이션(움짤 느낌, 무한 루프): 스포트라이트 빔 3개(호박 rgba(255,238,190,.55) / 레드 rgba(236,48,19,.4) / 블루 rgba(190,215,255,.42)) — clip-path 사다리꼴 + linear-gradient, transform-origin top, ±10° 좌우 스윙(4.6~6.4s ease-in-out alternate, 딜레이 각기 다름). 바닥에 blur 글로우 타원 2개가 좌우로 이동, 상단에 radial 헤이즈. **빔·글로우는 모두 오른쪽 절반(약 52% 이후, -40px 오프셋)에 배치 — 왼쪽 문구 영역에는 조명이 닿지 않음**
  - 무대 바닥: 하단 11% 높이의 어두운 스트립(#26262e→#121216), 상단 에지에 은은한 하이라이트 라인 — 버튼 아래를 지나도록 낮게 유지
  - 콘텐츠(z-index 위): 킥커 "BRASSONIT PRODUCTION"(12px/700, letter-spacing 2px, **"섭외"와 동일한 액센트색**) + 대형 헤드라인 흰색(clamp 36~60px/800, "섭외"만 액센트) + 버튼 2개. 체크리스트 문구 없음. 텍스트 블록은 컨테이너 정렬에서 20px 오른쪽 오프셋
  - 버튼: 아티스트 둘러보기 = solid 액센트 / 섭외 문의하기 = ghost(**rgba(13,13,18,.65) 반투명 다크 배경** + rgba(255,255,255,.45) 보더 + 흰 텍스트 — 배경 라인이 버튼 안으로 비치지 않도록). ghost hover는 rgba(255,255,255,.12)
- "브라소닛 기획공연" 섹션: 상단 1px 회색 룰, 제목 24px/800, **우측에 "더보기 ›" 텍스트 버튼(13px/600 #666, hover 액센트-700) → 공연 목록으로 이동**. 3단 그리드 공연 카드(이미지 16:10 → 날짜(13px 회색) → 제목(17px/800) → 한 줄 소개)

### 5. 공연 상세
- 브레드크럼: **홈 › 기획공연(클릭 시 공연 목록으로)**
- 좌 이미지(16:10) / 우: 킥커 + 제목(34px/800) + 일시·장소 / 소개 / 출연진 행 + 예매 버튼(예정 공연만, 지난 공연은 없음)
- 출연진: **칩/보더/밑줄 없이 소개 문구와 동일한 폰트·색상의 플레인 텍스트 버튼**(gap 12px), 클릭 시 해당 아티스트 상세로 이동. hover 시 색상 변화 없음(cursor:pointer만)
- 통계 줄: ♥ 좋아요 수 · 조회수 (12.5px #666, 플레인 텍스트)
- 버튼 줄(우측 정렬): **공연 문의하기(solid)** + **공유하기(ghost, 아티스트 상세와 동일 — URL 복사 후 2초간 "링크 복사됨 ✓")** + **♥ 찜 토글(ghost, 기본 #bbb·활성 시 액센트색, 좋아요 수 +1 반영)** — 아티스트 상세와 동일한 구조
- "공연 문의하기": **로그인 상태면 견적서 작성으로 바로 이동, 해당 공연이 자동 첨부됨(공연 정보 + 출연진 표시). 이때 화면 타이틀은 "공연 견적 요청"**. 비로그인 시 로그인 페이지로
- 하단 섹션 1 — **공연 소개**: 문단형 소개(max-width 960px, 15px/1.9). 접힘 상태에서 **5줄만 표시**(max-height 9.5em + 하단 페이드 마스크), [더보기 ↓]/[접기 ↑] 토글 버튼(전체 폭 1px #ccc 보더)
- 하단 섹션 2 — **공연 영상**: 아티스트 상세의 영상 섹션과 동일 — 유튜브 embed 세로 목록(max-width 960px, gap 48px), **5개까지 기본 표시**, 초과분은 [더보기 (n) ↓]/[접기 ↑] 토글

### 6. 카테고리 목록 / 검색 결과
- 브레드크럼(홈 › 카테고리 › 하위장르) + 5단 카드 그리드(1100px 이하 3단, 620px 이하 2단)
- 아티스트 카드: 정사각 이미지(hover 시 scale 1.04) → 이름(15.5px/700) → 소개 2줄 말줄임 → 하단 줄: ♥좋아요수 · 조회수(12.5px #666) + **우측에 좋아요(하트) 버튼과 장바구니 버튼 나란히**(1px #ccc 보더 아이콘 버튼, 활성 시 액센트색 채움). 좋아요가 장바구니 왼쪽
- 좋아요/장바구니는 로그인 필요(클릭 시 로그인 페이지로 유도)
- 데스크톱: 페이지당 20개 + 숫자 페이저 / 모바일: 무한 스크롤(+20)
- 검색 결과: 카테고리별 그룹 헤더(`카테고리 n팀`) 아래 카드 그리드, 결과 없으면 "검색결과가 없습니다."

### 7. 아티스트 상세
- 브레드크럼 + 좌: 정사각 이미지 슬라이더(좌우 화살표, 도트) / 우: 킥커(카테고리·장르) + 이름(34px/800) + 좋아요·조회 통계 + 장르/인원/소개 행(1px #ddd 룰)
- 버튼 줄: **섭외 견적 문의(solid)** — 로그인 시 장바구니와 무관하게 견적서 작성으로 바로 이동(해당 아티스트 1팀만 선택됨) / 장바구니 담기(ghost, 담기면 "장바구니에 담김 ✓") / 공유(URL 복사) / ♥(찜 토글, 찜 시 액센트색)

### 8. 로그인 / 회원가입
- 중앙 정렬 폼 max-width 420px. 입력창: 2px 검정 보더, 12px 14px 패딩, focus 시 액센트 보더
- 회원가입: 이메일 + 비밀번호(**8자 이상**) + 비밀번호 확인 → 가입 시 "인증 메일 발송" 안내 + "이메일 인증 완료하기 (데모)" 버튼(실서비스에서는 실제 메일 인증)
- 로그인 검증: 미가입/비밀번호 불일치/미인증 각각 에러 메시지(빨강 #d0342c). 성공 시 홈으로, 사용자명은 이메일 @ 앞부분
- 로그인 필요 기능 접근 시 "로그인이 필요한 기능입니다." 에러와 함께 로그인 페이지

### 9. 장바구니
- 브레드크럼 + 제목 "장바구니"(28px/800)
- 테이블형 리스트: 헤더 줄(2px 검정 하단 룰, 12px/700 #888 레이블) — [체크박스 "전체"] [아티스트] [카테고리] [버튼]
- 행(1px #ddd 하단 룰, 14px 상하 패딩): 체크박스(16px, accent-color 액센트) / 56px 정사각 썸네일 + 이름(클릭 시 상세) / `카테고리 · 장르` / "삭제" 버튼(1px #ccc 보더)
- 하단(2px 검정 상단 룰): 좌측 "선택 삭제"(체크된 것만 삭제) / 우측 **"총 n팀 아티스트로 견적 요청"** solid 버튼(내용 길이에 맞는 폭) → 체크된 아티스트로 견적서 작성 이동
- 진입 시 전체 선택 상태가 기본. 비어 있으면 안내 empty 문구

### 10. 견적서 작성
- 브레드크럼: 홈 › 장바구니 › 견적서 작성. 폼 max-width 640px
- 필드(레이블 12px/700 #888): 이메일(가입정보, readonly, 회색 배경) / 이름·전화번호(2단) / 제목 / 내용(textarea min-height 140px) / 첨부파일(파일 선택 버튼 + 파일명 목록, 개별 삭제) / **공연 선택 select** — "선택 시 공연과 출연진 목록이 함께 첨부됩니다"
- **폼 입력 보더는 1px #ccc(얇은 회색), focus 시 액센트** — 로그인 폼(2px 검정)과 다름에 유의
- 하단: "선택한 아티스트 n팀" 칩 목록(28px 썸네일 + 이름, 아티스트 없으면 섹션 숨김) / 공연 선택 시 "첨부된 공연" 박스(제목·일시·`출연진 자동 첨부 — 이름들`)
- 검증: 이름/전화번호/제목 필수. "견적서 보내기" 클릭 시 견적 생성 → 견적내역으로 이동(성공 배너), 발송된 아티스트는 장바구니에서 제거

### 11. 견적내역
- 테이블: [일자 130px] [상태 110px — 액센트 틴트 태그] [제목(f1) + 아래 메타 12px #888 "아티스트 n팀 · 공연 첨부 : 공연명"] [견적서 110px **좌측정렬**]
- 상태: 접수완료 → (회신 후) 회신완료. **견적서 컬럼: 회신완료 건은 다운로드 버튼(아이콘+"다운로드"), 미회신 건은 회색 "대기중"**. 데모에서는 다음날 자동 회신완료 처리 — 실제로는 서버 상태
- 최신순 정렬. **페이지당 10행, 초과 시 하단 숫자 페이징(‹ 1 2 … ›)**. 비어 있으면 empty 안내

### 12. 찜리스트
- 두 개의 테이블: **아티스트 목록** + 그 아래 **공연 목록**(공연 상세에서 ♥ 찜한 공연). 둘 다 장바구니와 동일한 테이블 디자인

## Responsive / 모바일 (breakpoints: 1100px / 860px / 620px)
데스크톱 우선 디자인이며, 아래 3개 브레이크포인트의 동작이 전부입니다. 이 외의 모바일 전용 레이아웃(햄버거 메뉴, 하단 탭바 등)은 **의도된 것이 아니므로 추가하지 마세요.**

**≤1100px**
- 아티스트 카드 그리드: 5단 → 3단
- 메가메뉴 컬럼: 3열로 축소

**≤860px**
- 아티스트/공연 상세: 좌 이미지 / 우 정보 2단 → 1단 (gap 32px)
- 공연 카드 그리드: 3단 → 1단
- 검색창 max-width 해제(전체 폭)

**≤620px**
- `.wrap` 좌우 패딩 96px → 20px
- 헤더: flex-wrap — 로고·아이콘 줄 아래로 검색창이 전체 폭 한 줄로 내려감(order:3, flex-basis:100%)
- GNB 탭: 가로 스크롤(스크롤바 숨김), 활성 밑줄(::after) 제거
- **메가메뉴 완전 숨김** — 대신 카테고리 목록 페이지 상단에 하위 장르 칩 바 표시
- 아티스트 카드 그리드: 2단. **그리드 자식에 `min-width:0` 필수** — 하단 통계/버튼 줄이 카드 최소폭을 밀어 이미지가 잘리지 않도록
- 아티스트 카드 하단 줄: **조회수(눈 아이콘) 숨김** — 좋아요 수 + 하트/장바구니 버튼만 표시(한 줄 유지)
- 아티스트 상세 버튼 줄: 섭외 견적 문의(텍스트 유지) + **장바구니·공유 버튼은 아이콘만 표시**(텍스트 숨김, flex:none) + ♥ — 한 줄 유지
- 푸터: flex-wrap — 1줄(로고+메뉴) / 2줄(© 카피라이트, flex-basis:100%)로 줄바꿈. 메뉴 글자가 세로로 꺾이지 않도록 white-space 유지
- 페이지네이션: 숫자 페이저 숨김 → **무한 스크롤(스크롤 하단 도달 시 +20개)**. 데스크톱은 숫자 페이저만
- 헤더 아이콘·카드의 탭 타겟은 44px 이상 유지

## Interactions & Behavior
- 페이지 전환 시 항상 scrollTo(0,0)
- 로그인 게이트: 좋아요/장바구니/견적 관련 전부. 비로그인 → 로그인 페이지 + "로그인이 필요한 기능입니다."
- 이미지 hover scale(0.4s), 버튼 hover는 액센트 램프(text #666→accent-700, solid 버튼은 accent-600), focus-visible 2px 액센트 아웃라인
- 사용자 드롭다운: 클릭 토글, 영역 mouseleave로 닫힘
- 공유 버튼: 클립보드 복사 후 2초간 "복사됨" 레이블

## State Management
- `user`(로그인 사용자명), `userEmail`, `accounts`(데모: localStorage)
- `liked`/`carted`: 아티스트 id → bool 맵. `showLiked`: 공연 idx → bool 맵(공연 찜). `cartSel`/`wishSel`/`showWishSel`: 체크박스 선택 맵
- `quotes`: 견적 배열 { date, status, title, artists[], show, doc } (데모: localStorage `brassonit-quotes`)
- 견적 폼: qfIds(선택 아티스트 id들), qfName/qfPhone/qfTitle/qfBody/qfFiles/qfShow — **qfShow가 있으면 화면 타이틀 "공연 견적 요청", 없으면 "섭외 견적 요청"(문의 모드는 "섭외 견적 문의")**
- 페이지 라우팅: `page` 값 (home | shows | show | list | search | detail | login | signup | cart | quote | quotes | wishlist | about | terms | privacy) — 실구현에서는 URL 라우팅으로
- 실서비스 치환 포인트: 계정/인증(메일 인증), 견적 CRUD·상태(접수완료/회신완료)·견적서 파일, 아티스트/공연 데이터 → API
